- kombucha-atlas.json — frame map
- assets/kombucha_idle.png
- assets/kombucha_run_1.png

- assets/kombucha_landing.png
- assets/kombucha_hurt.png
- assets/kombucha_collect.png
- assets/kombucha_game_over.png

Integration:
1. Replace the existing kombucha-atlas.png in the project root with the new one.
2. Copy the assets/ files into the project's assets/ folder, replacing the old Kombucha frame files.
3. If your game already points to kombucha-atlas.png, no code changes are needed.
4. If needed, keep frame order:
   idle, run_1, run_2, run_3, run_4, jump_launch, jump_air, double_jump, landing, hurt, collect, game_over.
