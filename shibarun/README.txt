Ozzy obstacle integration patch v3

Contains:
- index.html with the obstacle catalog updated to the new unified sticker-style obstacles.
- Transparent runtime PNGs for Tokyo, New York, Moscow, Rome, Madrid, Berlin, Amsterdam.

How to use:
1. Replace your existing index.html with this one.
2. Copy the included folders into your game root, merging with existing folders.
3. Keep your current backgrounds/audio/skins; this patch only swaps obstacle art + catalog setup.

Also included separately:
- /mnt/data/ozzy-obstacles-v3-artpack-512.zip with 512x512 centered transparent versions of the same assets.
- /mnt/data/ozzy-obstacles-v3-preview.png as a quick visual check.
